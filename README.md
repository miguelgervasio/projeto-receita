# receita-cupcake

**receita-cupcake** é um projeto front-end básico desenvolvido utilizando HTML e CSS, criado para praticar os primeiros conceitos de estruturação e estilização de páginas web.

## Índice

- [Visão Geral](#visão-geral)
- [Tecnologias Utilizadas](#tecnologias-utilizadas)

## Visão Geral

O **receita-cupcake** foi desenvolvido no início dos meus estudos em desenvolvimento web, com o objetivo de praticar a estruturação de conteúdo com HTML e a estilização utilizando CSS.

O projeto consiste em uma página simples de receita, apresentando imagem, título, descrição, tempo de preparo, rendimento, dificuldade e lista de ingredientes.

A aplicação foi construída com foco na organização semântica dos elementos, estrutura correta do conteúdo e aplicação de estilos para melhorar a apresentação visual da página.

## Tecnologias Utilizadas

- **HTML**: Linguagem de marcação utilizada para estruturar o conteúdo da página.
- **CSS**: Linguagem de estilização utilizada para definir layout, cores, tipografia e espaçamentos.
